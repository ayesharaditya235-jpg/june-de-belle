\## Tentang Aplikasi

June de Belle adalah platform pre-order online untuk produk tas \& organizer 

yang ergonomis, ringan, dan estetik. Ditujukan untuk pelajar SMA usia 15-18 

tahun yang butuh solusi tas sekolah yang nyaman sekaligus stylish.



\## Produk

\- Tote Bag

\- Tempat Pensil

\- Inner Bag Pouch Organizer (coming soon)



\## Fitur

\- Product showcase dengan image carousel \& color variant picker

\- Form pre-order terintegrasi

\- Notifikasi WhatsApp otomatis ke owner via Fonnte

\- WhatsApp redirect dengan pesan pre-filled

\- Dashboard admin (login-protected)

\- RLS aktif di Supabase



\## Tech Stack

\- Next.js 15 + TypeScript + Tailwind CSS

\- Supabase (PostgreSQL + RLS)

\- Fonnte (WA notification)

\- Vercel (hosting)



\## Setup Lokal

1\. Clone repo

git clone https://github.com/ayesharaditya235-jpg/june-de-belle.git

2\. Install dependencies

npm install

3\. Buat file `.env.local` dan isi:

NEXT\_PUBLIC\_SUPABASE\_URL=...

NEXT\_PUBLIC\_SUPABASE\_ANON\_KEY=...

SUPABASE\_SERVICE\_ROLE\_KEY=...

FONNTE\_TOKEN=...

ADMIN\_PASSWORD=...

4\. Jalankan development server

npm run dev
